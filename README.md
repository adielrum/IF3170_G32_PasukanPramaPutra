## ⚙️ Requirement & Instalasi

### Prasyarat Package

- numpy>=2.3.2
- matplotlib>=3.10.6

### Instalasi Package

1. Clone repository.

   ```bash
   git clone https://github.com/adielrum/IF3170_G42_PasukanPramaPutra.git
   cd IF3170_G42_PasukanPramaPutra
   ```

2. Pasang dependensi.

   ```bash
   pip install -r requirements.txt
   ```

   Jika file `requirements.txt` belum ada, bisa install manual.

   ```bash
   pip install numpy matplotlib
   ```
